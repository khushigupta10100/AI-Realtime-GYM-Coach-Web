Capabilities

Features

Built around the coaching tools already available in this application.

AI Pose Detection

Uses on-device pose estimation to identify body position while you train in front of the camera.

Real-Time Exercise Monitoring

Streams your webcam into the coach so movement can be observed as the set happens.

Automatic Repetition Counting

Counts reps from movement stages for supported exercises such as squats, push-ups, curls, presses, and lunges.

Posture Analysis

Tracks exercise-specific cues such as joint angles, depth, alignment, and stability indicators.

Instant Workout Feedback

Shows live metrics during a session and can deliver coach messages through the existing voice coaching pipeline.

Workout Progress Tracking

Stores completed exercise data and displays workout history on the coach dashboard.
